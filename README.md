# Data Structures & Algorithms in C

A collection of Data Structures and Algorithms implemented from scratch in C, built as a personal learning project to strengthen core CS fundamentals.

## 📌 About

This repository contains hand-written implementations of common data structures and algorithms in C, without relying on external libraries. The goal is to understand how these structures work internally — memory management, pointers, and algorithmic logic — rather than just using built-in library functions.

## ✨ Features

- Linked list operations: creation, insertion (front/end/middle), deletion (front/end/middle), traversal
- Clean, beginner-friendly C code with comments
- Modular functions that can be reused across programs
- Focus on manual memory management using `malloc`/`free`
- Test cases included in `main()` for each structure

## 🎯 Goals

- Build a solid, from-scratch understanding of core data structures
- Practice writing memory-safe, bug-free C code
- Create a reusable reference repository for interview preparation
- Document each implementation clearly enough for others to learn from it

## 🚀 Future Plans

- Add stacks, queues, trees, and graphs
- Add time and space complexity notes for each implementation
- Write unit tests for edge cases (empty list, single node, duplicates)
- Add a Makefile for easier compilation
- Possibly port select structures to C++ for comparison

## 📚 Learning Objectives

- Strengthen understanding of pointers and dynamic memory allocation
- Learn to reason about edge cases (empty structures, single elements, boundaries)
- Practice debugging memory issues (dangling pointers, memory leaks)
- Build intuition for time/space complexity trade-offs
- Get comfortable reading and writing modular, readable C code

## 🛠️ Tech Stack

- **Language:** C
